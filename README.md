# Data Warehouse – Sistem Rekam Medis Elektronik (RME)

Implementasi Data Warehouse untuk mendukung integrasi dan pengelolaan data dari Sistem Rekam Medis Elektronik (RME). 
Data dari berbagai sumber diolah melalui proses ETL (Extract, Transform, Load) dan disimpan dalam Data Warehouse untuk menghasilkan data yang terstruktur serta mendukung kebutuhan analisis dan pelaporan.

## 🚀 Fitur

- Menggabungkan data dari berbagai sumber sistem RME
- Menyediakan format data yang terstruktur untuk analisis
- ETL (Extract, Transform, Load)
    Extract: mengambil data dari sumber
    Transform: membersihkan dan menyesuaikan format data
    Load: memasukkan data yang telah diproses ke Data Warehouse
- Pembersihan data yang tidak valid
- Penyesuaian format dan struktur data
- Mapping data dari sumber ke Data Warehouse
- Mendukung analisis historis data kesehatan
